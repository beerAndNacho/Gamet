# Vaultbound: Night Shift

**탑다운 픽셀 잠입·금고 복구 어드벤처** — 야간 복구팀의 사무실에서 계약과 동료를 고르고, 폐쇄 시설에 잠입해 보안 회로를 끊은 뒤 금고 속 발견물의 운명을 결정합니다.

## 1.1 고도화 업데이트

이번 버전은 같은 현장을 다시 플레이해도 다른 전략이 필요하도록 반복 플레이 구조를 강화했습니다.

- 작업일·현장별로 결정되는 **야간 지령 9종**
- 위험 계약 기본 보수 1.18~1.40배와 추가 도전 수당
- 근접 회피·완벽 해킹·무경보 진입 등을 평가하는 **NIGHT STYLE C~S 랭크**
- 박물관·중앙은행·B-7에 적용되는 **보스 전용 프로토콜 12단계**
- 잠금축 전환 때 표시되는 픽셀 보스 컷인과 실시간 프로토콜 HUD
- 여섯 동료의 관계 레벨 2·4·6 전용 에피소드, 총 18개
- 표준 게임패드 이동·메뉴·해킹·대시·동료 스킬·RT 압력 조작
- 기존 저장 데이터와 호환되는 별도 고도화 기록

상세 설계는 [`docs/ADVANCED_SYSTEMS.md`](./docs/ADVANCED_SYSTEMS.md)에 정리했습니다.

## 핵심 플레이 루프

1. 픽셀 사무실에서 계약 게시판, 장비 작업대, 기록실과 동료 NPC를 직접 찾아갑니다.
2. 열 개 현장의 지령·보수·추가 도전을 비교해 계약을 선택합니다.
3. 탑다운 현장에서 경비 시야와 카메라를 피해 배전반을 해킹합니다.
4. 압력·열·소음·내용물 상태를 관리하며 일반 또는 보스 금고를 해체합니다.
5. 세 개의 보관함 중 하나를 선택해 발견물을 회수합니다.
6. 반환, 증거 보관, 경매 중 하나를 선택해 코인·평판·정보·사건 단서를 성장시킵니다.
7. 스타일 수당과 지령 도전을 정산하고 동료 관계 에피소드를 해제합니다.

## 주요 콘텐츠

- 384×672 내부 해상도와 `image-rendering: pixelated` 기반 픽셀 렌더링
- 직접 이동 가능한 사무실과 10개 현장 맵
- 경비·카메라·드론·레이저·은신·대시·수집품
- 타이밍형 배전반 해킹
- 압력·열·소음·내용물 상태·콤보·돌발 이벤트 금고 해체
- 6명의 동료와 고유 패시브/액티브 스킬, 관계 레벨
- 30종 발견물, 4단계 희귀도, 연결 사건 3개
- 6종 장비 강화와 3일 단위 야간 근무 목표
- Web Audio API 기반 칩튠 BGM과 효과음
- 브라우저 자동 저장, 이전 버전 데이터 마이그레이션, PWA 오프라인 캐시

## 조작

### PC

- 이동: `WASD` 또는 방향키
- 상호작용: `E`, `Space`, `Enter`
- 대시: `Shift`
- 동료 능력: `F`
- 일시정지: `Escape`

### 모바일

화면 하단 방향키, `A` 조사, `RUN` 대시, `동료` 버튼을 사용합니다. 금고에서는 `누르고 유지` 버튼으로 압력을 조절합니다.

### 게임패드

- 이동·메뉴: 왼쪽 스틱 또는 D-pad
- 조사·확정·해킹: `A`
- 대시: `B` 또는 `LT`
- 동료 능력: `X`
- 금고 압력: `RT`
- 메뉴 이동: `LB` / `RB`
- 일시정지: `START`

## 실행

Node.js 20 이상에서 외부 런타임 라이브러리 없이 실행됩니다.

```bash
npm run dev
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 검증

```bash
npm run check
npm test
npm run simulate
```

- `check`: JavaScript 문법, DOM ID, import, PWA 캐시와 고도화 연결 검사
- `test`: 핵심 엔진과 지령·스타일·보스·관계·게임패드 테스트
- `simulate`: 10개 현장의 경제 구조와 지령 9종·보스 12단계를 결정론적으로 검사
