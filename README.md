# VAULT RECOVERY · 금고 복구사

폐점한 은행과 봉인 시설의 금고를 복구하고, 발견한 물건을 경매하거나 주인에게 돌려주는 모바일 우선 웹게임 MVP입니다.

## 핵심 플레이

1. 평판과 보유 코인에 맞는 복구 의뢰를 선택합니다.
2. 버튼을 누르면 압력이 올라가고, 손을 떼면 압력과 열·소음이 내려갑니다.
3. 압력 바를 움직이는 `SAFE` 구간에 유지하면 잠금축 해체가 빠르게 진행됩니다.
4. 금고를 열면 물품의 희귀도·보존 상태·감정가가 결정됩니다.
5. `즉시 경매`로 코인을 확보하거나 `주인에게 반환`해 평판을 크게 올립니다.
6. 정밀 드릴, 냉각기, 흡음재, 투과 스캐너를 강화해 다음 지역을 개방합니다.

모바일에서는 큰 작업 버튼을 누르고 유지하며, PC에서는 `Space` 키로 동일하게 조작할 수 있습니다. 진행 상황은 브라우저 `localStorage`에 자동 저장됩니다.

## 실행

별도 패키지 설치가 필요하지 않습니다. Node.js 20 이상에서 다음 명령을 실행하세요.

```bash
npm run dev
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 테스트

```bash
npm run check
npm test
```

- `npm run check`: JavaScript 문법, 필수 정적 파일, JSON 설정을 검사합니다.
- `npm test`: 업그레이드, 압력 제어, 실패 조건, 보상·수집 로직을 Node 내장 테스트 러너로 검증합니다.

## 기술 구성

- 의존성 없는 HTML/CSS/ES Modules
- 모바일 세로 화면과 데스크톱 대응 반응형 UI
- Web Audio API 효과음 및 진동 피드백
- 서비스 워커 기반 오프라인 캐시
- 설치 가능한 PWA 매니페스트
- GitHub Actions CI
- Vercel 정적 배포 설정

## 현재 MVP 콘텐츠

- 복구 지역 4개
- 발견물 16종과 4단계 희귀도
- 장비 4종, 각 6단계 강화
- 압력·열·소음·내용물 상태·시간 제한 시스템
- 경매/반환 선택과 평판 기반 지역 잠금 해제
- 발견물 기록실과 최근 복구 내역
