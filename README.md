# Vaultbound: Night Shift

**금고 복구사 픽셀 어드벤처** — 야간 복구팀의 사무실을 돌아다니며 의뢰를 고르고, 폐쇄 시설에 잠입해 보안 회로를 끊고, 금고를 해체해 발견물의 운명을 결정하는 모바일 우선 픽셀 인디게임입니다.

## 지금 플레이할 수 있는 핵심 루프

1. 픽셀 사무실에서 계약 게시판, 장비 작업대, 기록실과 동료 NPC를 직접 찾아갑니다.
2. 열 개의 현장 중 평판과 보유 코인에 맞는 의뢰를 선택합니다.
3. 탑다운 현장에서 경비 시야와 카메라를 피해 배전반을 해킹합니다.
4. 움직이는 안전 구간에 압력을 유지하며 3중 또는 4중 잠금축을 해체합니다.
5. 세 개의 보관함 중 하나를 선택해 발견물을 회수합니다.
6. 반환, 증거 보관, 경매 중 하나를 선택해 코인·평판·정보·사건 단서를 성장시킵니다.

## 주요 콘텐츠

- 384×672 내부 해상도, `image-rendering: pixelated` 기반 픽셀 렌더링
- 직접 이동 가능한 사무실과 현장 맵
- 폐점은행부터 국고 벙커 B-7까지 10개 현장
- 경비·카메라·드론·레이저·은신·대시·수집품
- 타이밍형 배전반 해킹
- 압력·열·소음·내용물 상태·콤보·돌발 이벤트를 관리하는 금고 해체
- 6명의 동료와 고유 패시브/액티브 스킬, 관계 레벨
- 30종 발견물과 4단계 희귀도
- 연결 사건 3개와 단계별 사건 장
- 6종 장비 강화와 3일 단위 야간 근무 목표
- 브라우저 자동 저장과 이전 버전 저장 데이터 마이그레이션
- Web Audio API 기반 칩튠 BGM과 효과음
- 모바일 방향키/버튼 및 PC 키보드 동시 지원

## 조작

### PC

- 이동: `WASD` 또는 방향키
- 상호작용: `E`, `Space`, `Enter`
- 대시: `Shift`
- 동료 능력: `F`
- 일시정지: `Escape`

### 모바일

화면 하단 방향키, `A` 상호작용, `RUN` 대시, `동료` 버튼을 사용합니다. 금고 화면에서는 `누르고 유지` 버튼으로 압력을 조절합니다.

## 실행

Node.js 20 이상에서 외부 라이브러리 없이 실행됩니다.

```bash
npm run dev
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 검증

```bash
npm run check
npm test
npm run simulate
```

- `check`: JavaScript 문법, DOM ID, 내부 import, PWA 캐시와 픽셀 렌더링 설정 검사
- `test`: 콘텐츠·저장 이전·동료·계약·보상·수집·사건·관계도 검증
- `simulate`: 10개 현장의 보상과 진행 구조를 결정론적으로 시뮬레이션
