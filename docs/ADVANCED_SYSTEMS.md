# Vaultbound 1.1 — Advanced Systems

이번 버전의 목표는 단순히 현장 수를 늘리는 것이 아니라 **같은 현장도 다른 판단과 리듬으로 플레이하게 만드는 것**이다. 기존 잠입 → 해킹 → 금고 해체 → 발견물 선택의 핵심 루프를 유지하면서, 야간 지령·스타일 랭크·보스 전용 프로토콜·관계 에피소드·게임패드 조작을 추가한다.

## 1. 야간 지령

각 작업일과 현장 조합으로 지령이 결정된다. 결과는 결정론적이므로 새로고침으로 유리한 계약만 다시 뽑을 수 없고, 같은 날짜의 계약 게시판은 항상 같은 조건을 표시한다.

| 지령 | 위험 변화 | 추가 도전 |
|---|---|---|
| 표준 회수 | 기본 규칙 | 없음 |
| 무음 감사 | 경보와 금고 소음 상승 | 최종 경보 20% 이하 |
| 재잠금 임박 | 현장·금고 시간 감소 | 금고 시간 10초 이상 남기기 |
| 불안정 잠금망 | 안전 구간 축소·이벤트 가속 | 콤보 ×4 |
| 순환 정전 | 시야 증가·주기적 암전 | 모든 배전반 완벽 해킹 |
| 추적조 투입 | 정예 경비 1명 추가 | 근접 회피 2회 |
| 취약 증거물 | 열·과압 손상 증가 | 내용물 상태 82% 이상 |
| 흔적 없는 침투 | 대시 없이 진행 | 대시 미사용 |
| 비인가 현금 수송 | 현장 수집품 추가 | 수집품 4개 이상 |

지령은 기본 보수를 1.18~1.40배 올리고, 별도 도전 달성 시 기본 보수의 14~20%를 추가 지급한다. 난도 상승이 단순 불이익이 아니라 명확한 수익 선택이 되도록 설계했다.

## 2. NIGHT STYLE

플레이어의 행동을 점수화해 결과 화면에서 C~S 스타일 랭크를 부여한다.

- 경비와 가까운 거리에서 발각되지 않고 통과: `CLOSE CALL +32`
- 완벽 해킹: `PERFECT HACK +95`
- 현장 현금·정보 회수: `PICKUP +18`
- 낮은 경보로 금고실 진입: `GHOST ENTRY +125`
- 보스 프로토콜 정확 대응: `PROTOCOL CLEAR +45`
- 잠금축 손상 2.5% 이하: `FLAWLESS LOCK +58`

| 랭크 | 점수 | 추가 수당 |
|---|---:|---:|
| C · CAREFUL | 0 | 없음 |
| B · CLEAN | 110 | 기본 보수 5% |
| A · SHADOW | 245 | 기본 보수 10% |
| S · PHANTOM | 420 | 기본 보수 18% |

스타일 점수는 실패 시 현금으로 전환되지 않는다. 따라서 무리하게 점수를 노릴지, 안전하게 발견물을 확보할지 선택하게 된다.

## 3. 보스 금고 프로토콜

보스 현장은 단순히 잠금축 수만 많은 금고가 아니다. 각 잠금축의 규칙이 바뀌고, 진입 시 픽셀 컷인이 표시된다.

### 구시립박물관 비공개 수장고

1. **유물 보존 펄스** — 붉은 펄스 동안 압력을 반드시 해제한다.
2. **기억 봉인** — 안전 구간이 잠시 사라지므로 마지막 위치를 기억한다.
3. **복원 극성** — LEFT/RIGHT 지시에 맞는 안전 구간 절반을 사용한다.
4. **큐레이터 최종 승인** — 더 짧은 보존 펄스를 연속으로 견딘다.

### 구 중앙은행 봉인 아카이브

1. **이중 장부** — 차변과 대변에 따라 압력 방향이 전환된다.
2. **복리 과열** — 시간이 흐를수록 열 발생률이 가속된다.
3. **검게 지운 창** — 장시간 센서 암전을 기억으로 버틴다.
4. **마감 결산** — 손을 떼면 해체 진행도가 조금씩 회수된다.

### 국고 벙커 B-7

1. **영점 압력** — 외부 압력장이 게이지를 좌우로 흔든다.
2. **삼중 보안 스캔** — 짧은 스캔이 빠르게 반복된다.
3. **무음 명령** — 소음 상승률이 급증한다.
4. **월식 코어** — 청록색 박동 창에서만 압력을 인가하는 리듬 최종전이다.

## 4. 관계 에피소드

여섯 동료 모두 관계 레벨 2·4·6에 전용 에피소드가 열린다. 총 18개 에피소드이며, 사무실 복귀 시 한 번만 재생된다.

- 윤서진: 비상 정지를 고집하게 된 사고와 B-7 공동 정지
- 박하린: 이름 없는 기록 카드와 608호의 가족 기록
- 강민혁: 침수 구조 사고와 둘이 살아 돌아오는 계획
- 오주노: 실패한 드릴 1·2호와 동료를 위한 4호기
- 한재욱: 17번 계좌에 남은 자신의 서명
- 나비: 삭제 명령을 거부하고 동료라는 분류를 선택한 기록

에피소드 완료 시 소량의 코인과 정보가 지급되며, 중복 재생은 별도의 고도화 저장 데이터로 방지한다.

## 5. 게임패드

표준 게임패드 매핑을 지원한다.

- 왼쪽 스틱 / D-pad: 이동 또는 메뉴 탐색
- A: 조사·선택·해킹
- B / LT: 대시
- X: 동료 스킬
- RT: 금고 압력 인가
- LB / RB: 메뉴 이전·다음
- START: 일시정지

게임패드가 연결되면 화면에 연결 배지가 표시된다. 키보드와 게임패드 입력은 동시에 사용할 수 있고, 연결이 끊기면 눌림 상태를 즉시 해제한다.

## 6. 저장과 호환성

기존 핵심 저장 데이터는 그대로 유지한다. 다음 고도화 정보는 별도 키에 보관한다.

- 본 스타일 최고 점수
- 지령 완료 및 추가 도전 횟수
- 보스별 클리어 횟수
- 누적 근접 회피
- 시청한 관계 에피소드
- 게임패드 안내 확인 여부

게임 전체 초기화 시 고도화 데이터도 함께 초기화된다.

## 7. 검증 범위

- 지령 9종의 결정론적 순환과 보상 계산
- 스타일 점수와 C/B/A/S 경계
- 지령별 도전 판정
- 세 보스 × 네 프로토콜 선택
- 펄스·극성·리듬·압력장 효과
- 관계 에피소드 해금 및 중복 방지
- 게임패드 스틱·D-pad·버튼·트리거 매핑
- 기존 픽셀 게임 엔진 테스트와 10개 현장 보상 시뮬레이션
- 고도화 지령 9종과 보스 프로토콜 12단계 시뮬레이션
