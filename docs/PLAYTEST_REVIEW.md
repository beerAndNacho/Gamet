# Vaultbound v1.2 직접 플레이 검수 기록

## 검수 범위

모바일 기준 390×844 브라우저 환경에서 다음 흐름을 직접 진행했다.

1. 타이틀에서 새 근무 시작
2. 튜토리얼 대화 종료 후 작업실 이동
3. 계약 게시판에서 10개 의뢰 확인
4. 폐점은행 17호 출동
5. 현장 목표를 따라 배전반 접근
6. 타이밍 해킹 성공
7. 금고실 이동 및 금고 해체
8. 보관함 선택
9. 발견물 확인 및 원주인 반환
10. 정산 후 작업실 복귀

자동 테스트와 달리 화면 배치, 목표 발견 가능성, 손을 누르고 떼는 실제 입력 비율, 대기 연출과 결과 전환까지 포함해 확인했다.

## 발견한 핵심 문제

### 1. 첫 금고가 사실상 완주 불가능

기존 입문 금고는 42초 안에 3개의 잠금축을 각각 100% 해체해야 했다. 압력은 초당 약 43 상승하고 31 하락했기 때문에 안전 압력을 유지하려면 상당 시간을 냉각에 써야 했지만, 해체 진행은 안전 구간에서 누르고 있을 때만 약 초당 5.8 증가했다.

여러 자동 압력 제어 전략을 실제 게임 업데이트 루프에 적용했으나 첫 잠금축을 완료한 뒤 두 번째 잠금축 2~12% 구간에서 시간이 끝났다. 내용물 상태가 100%인 상태에서도 `vault-timeout`이 발생했으므로 숙련도보다 수학적 처리량의 문제였다.

### 2. 열 개 현장이 같은 구조로 느껴짐

현장 이름과 팔레트, 경비 유형은 달랐지만 실제 벽과 배전반, 금고 배치는 하나의 기본 구조를 반복했다. 스테이지를 해금해도 새로운 장소를 탐험한다는 보상이 약했다.

### 3. 큰 현장에서 현재 목표를 찾기 어려움

목표 문장은 있었지만 방향과 거리가 없었다. 40×48 타일 맵에서 첫 배전반이 화면 밖에 있으면 어느 방향으로 움직여야 하는지 알기 어려웠다. 이는 난이도라기보다 길찾기 정보 부족에 가까웠다.

### 4. 초반 평판 진행이 느림

두 번째 계약은 평판 4가 필요했지만 첫 의뢰의 일반적인 반환 보상은 평판 3이었다. 첫 판을 잘 끝내도 동일 의뢰를 한 번 더 반복해야 해 초반 템포가 느려졌다.

## 적용한 수정

### 금고 밸런스

- 입문 금고를 3중 잠금에서 2중 잠금으로 변경
- 입문 제한 시간을 58초로 확대
- 입문 SAFE 구간을 약 33% 폭으로 확대
- 압력 상승 속도를 낮추고 손을 뗐을 때 감압 속도를 높임
- 안전 구간 해체 속도를 약 두 배 수준으로 재조정
- 냉각을 위해 손을 떼도 콤보가 즉시 무너지지 않는 0.55초 유예 적용
- 입문 의뢰에서 한 번만 작동하는 12초 구조 시간 추가
- 일반 금고 3중 잠금, 보스 금고 4중 잠금 정체성은 유지
- 현재 잠금축뿐 아니라 전체 금고 해체 비율을 표시

수정 후 동일한 보수적 압력 제어로 입문 금고를 약 21.4초에 완료했고, 36초 이상을 남겼으며 내용물 상태 100%, 최대 콤보 5를 기록했다.

### 현장 구조

`src/mission-layouts.js`에 10개 전용 구조를 추가했다.

- 폐점은행: 칸막이와 은행 창구형 통로
- 백야호텔: 객실과 중앙 홀
- 수몰지점: 세로 수로와 침수 구획
- 카지노: 중앙 게임 플로어와 외곽 통로
- 박물관: 전시실과 보존 구역
- 야간 열차: 길고 좁은 객차 구조
- 비밀 창고: 상자 미로와 교차 통로
- 극저온 금고: 냉각 구획과 분리 벽
- 봉인 아카이브: 반복 서가형 통로
- 국고 벙커: 다중 검문 구획

각 배전반과 금고까지 실제로 도달할 수 있는 경로를 생성한 뒤 테스트에서 BFS로 재검증한다. 경비 순찰 경로도 벽으로 막히지 않도록 별도로 확보했다.

### 목표 안내

- 화면 상단 중앙에 목표 방향과 타일 거리 표시
- 목표가 화면 안에 있으면 `TARGET` 표식 표시
- 목표가 화면 밖이면 화면 가장자리에 방향 화살표 표시
- 배전반을 모두 완료하면 안내 대상이 자동으로 금고로 전환

### 진행 속도

현장 평판 요구량을 다음과 같이 완화했다.

```text
0 → 3 → 7 → 12 → 18 → 25 → 33 → 42 → 52 → 63
```

첫 의뢰를 높은 상태로 반환하면 평판 5를 얻어 두 번째 현장을 즉시 해금할 수 있다.

## 자동 검증

- 정적 검사 통과
- 전체 테스트 31개 통과
- 열 개 현장 모두 배전반·금고 접근 가능
- 열 개 현장 맵 서명 모두 서로 다름
- 무개조 기준 모든 금고 기계적 완주 가능
- 기존 지령 9종·보스 프로토콜 12단계 시뮬레이션 유지
- 초반 평판 곡선 테스트 추가
